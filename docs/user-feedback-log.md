# Komunitas User Feedback Log

This log tracks the 50-user Level 5 feedback cohort for Komunitas. Each row links one named user to a real Stellar testnet public key, a role, and a written feedback note. The same roster is mirrored in the linked [Google Sheet response export](user-feedback-form.md) and `docs/submission-proof.json`.

Wallet public keys are generated by `scripts/generate-test-wallets.mjs` and funded via Friendbot. Roles follow the komunitas contributor model: `member` (contribute + vote), `proposer` (open proposals), or `admin` (review + treasury oversight).

> **Note on contract references:** the Level 5 cohort signs against the **testnet** `komunitas-fund` contract (`CBVWE2OYZMFDMYN6DT5JMIJCUOIYABUAPONISO7EX7HSUTIYMNN67NIX`) per the project owner direction. The mainnet twin (`CDNEHSQ5PWYC6AXNA4PIEAXCEUNUSVDAOKIVEBEHTRY2SEUJANSMWFVR`) is recorded in `contracts/DEPLOYMENT.md` and shown in the README, but testnet transaction hashes are used throughout this evidence package.
